# ⚕️ Exploring Obesity Trends Through Cloud-Based Analytics

Obesity is a growing global health concern influenced by various demographic, dietary, and lifestyle factors. This project aims to **explore obesity trends and predict obesity levels using a cloud-based data analytics framework**.

The analysis uses the **Obesity Level Assessment Based on Dietary Habits and Physical Condition** dataset, containing **2,111 records and 17 attributes**, including demographic information, physical measurements, dietary behaviours, physical activity, lifestyle habits, and obesity categories.

A complete data lifecycle was implemented using **Google Cloud Platform (GCP)**. Raw data is stored in **Google Cloud Storage (GCS)**, while **BigQuery** is used for data preprocessing, feature engineering, and standardized data storage. The processed data is then integrated with **Google Colab** for Machine Learning and interactive data visualization.

Three Machine Learning classifiers — **Random Forest, Gradient Boosting, and Logistic Regression** — were developed and evaluated to predict seven obesity categories. Random Forest achieved the highest performance with **98.80% accuracy**.
